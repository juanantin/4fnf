# Four Friends & Family ($4FNF)

Next.js 15 landing page for an independent BNB Chain meme token.

## Run

`npm install && npm run dev`

## Vercel

Import this repository in Vercel. Framework: Next.js. Root directory: repository root. No required environment variables.

When verified, set `NEXT_PUBLIC_TOKEN_ADDRESS` to the actual token contract address to activate the PancakeSwap link.

## On-chain data

Reads BNB balance for the project-supplied SAFU address using public BSC JSON-RPC. This is **not** a donation total. Donation totals remain blank pending verified attribution, token contract, and donation mechanism. Address ownership is not independently verified.
